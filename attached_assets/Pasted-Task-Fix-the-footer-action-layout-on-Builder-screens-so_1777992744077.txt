- Their internal vertical alignment must match
- Text and icons must be vertically centered
- Padding must be consistent with DS
- Border radius must match DS
- Use the shared Button component / Core DS wrapper, not custom ad hoc styling

The buttons do NOT need to have the same visual variant:
- "Назад" = secondary
- "Далее" = primary
But they must still feel like paired controls with the same height and proper alignment.

3. FIX ICON SPACING / ALIGNMENT

- Use the same layout on all step screens
