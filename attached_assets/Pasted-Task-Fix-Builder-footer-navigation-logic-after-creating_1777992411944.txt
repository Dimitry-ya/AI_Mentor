Task: Fix Builder footer navigation logic after creating a trainer or exam.

Project path:
artifacts/ai-mentor

Current problem:
When the user creates a new trainer or exam and enters the Builder editor, the bottom footer shows:
- "Сохранить черновик"
- "Исправить ошибки"

This is wrong for the creation/editing flow.

Required UX:
The Builder is a step-by-step creation flow:
1. Онбординг
2. Теория
3. Практика
4. Завершение

In this flow the bottom footer must help the user move through steps, not save drafts or jump to errors.

Required footer behavior:
- Replace "Сохранить черновик" with "Назад"
- Replace "Исправить ошибки" with "Далее"
- "Назад" moves to the previous step
- "Далее" moves to the next step
- Do not show "Сохранить черновик" in this creation flow
- Do not show "Исправить ошибки" as the primary CTA in this creation flow

Important:
Do not rewrite the app.
Do not change routes.
Do not change data model.
Do not change localStorage key ai-mentor:v1.
Do not remove autosave/local persistence if it already exists.
Only remove the visible "Сохранить черновик" action from this flow.
Do not remove validation logic.
Do not remove error indicators.
Do not remove the problems panel.

==================================================
EXPECTED UX LOGIC
==================================================

1. On step 1: "Онбординг"
Footer should show:
- "Назад" as secondary, disabled or returning to previous screen/catalog depending on existing navigation model
- "Далее" as primary

Clicking "Далее":
- validates the current step if validation exists
- if valid, moves to step 2 "Теория"
- if invalid, stays on current step and shows validation feedback
- button label remains "Далее", not "Исправить ошибки"

2. On step 2: "Теория"
Footer should show:
- "Назад"
- "Далее"

Clicking:
- "Назад" moves to "Онбординг"
- "Далее" moves to "Практика" if valid, or shows validation feedback if invalid

3. On step 3: "Практика"
Footer should show:
- "Назад"
- "Далее"

Clicking:
- "Назад" moves to "Теория"
- "Далее" moves to "Завершение" if valid, or shows validation feedback if invalid

4. On step 4: "Завершение"
Footer should show:
- "Назад"
- "Опубликовать" or the existing final primary action if already implemented

Do not show "Далее" after the final step.
