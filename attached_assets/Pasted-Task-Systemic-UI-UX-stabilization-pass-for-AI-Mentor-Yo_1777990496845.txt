==================================================
UX PRINCIPLES TO FOLLOW
==================================================

Apply these principles while fixing UI:

1. Main action must be obvious.
Users should immediately understand what they can do next.

2. Reduce visual noise.
Do not add excessive badges, icons, shadows, borders, decorative elements or competing accents.

3. Calm enterprise UI.
The interface should feel stable, clean, predictable and bank-grade.

4. Consistency over local fixes.
If a visual pattern appears in multiple places, fix the shared component or shared layout, not one instance.

5. User control.
Do not overload the modal with redundant actions. If the close icon already closes the popup and the main CTA is clear, remove unnecessary secondary actions such as "Отмена" from this popup.

6. Recognition over recall.
Controls should be visually recognizable and consistent: buttons, selects, cards and stepper must look and behave the same across the app.
