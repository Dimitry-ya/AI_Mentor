# AI Mentor

AI Mentor — веб-приложение для создания, проверки, публикации и прохождения обучающих сценариев внутри корпоративной среды.

Проект ориентирован на внутренние образовательные сценарии: тренажёры, экзамены, симуляции диалогов, проверку готовности материалов и аналитику прохождения.

## Статус проекта

Текущая версия — прототип / рабочий MVP, перенесённый из Replit в GitHub.

Сейчас интерфейс реализован на React, TypeScript, Vite, Tailwind и shadcn/ui. Следующий этап — перевод интерфейса на Core DS.

Дизайн-система:
https://core-ds.github.io/core-components/master/

## Основные возможности

- Каталог обучающих материалов
- Поиск и фильтрация обучений
- Создание и редактирование тренажёров
- Конструктор сценариев
- Проверка готовности сценария
- Preview-режим
- Sandbox-режим
- Learner-режим для прохождения
- Аналитика прохождений
- Управление доступами сотрудников
- Моковая оценка ответа пользователя
- Хранение состояния в localStorage

## Основные маршруты

| Маршрут | Назначение |
|---|---|
| `/catalog` | Каталог обучений |
| `/analytics` | Аналитика |
| `/admin/access` | Управление доступами |
| `/builder/:id` | Конструктор обучения |
| `/preview/:id` | Предпросмотр сценария |
| `/sandbox/:id` | Тестовая среда |
| `/learner/:id` | Прохождение обучения |
